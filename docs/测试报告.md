## 布林带股票策略原理

布林带用三条线描述价格相对近期均值的位置和波动范围：

- **中轨**：N 日简单移动平均线。
- **上轨**：中轨 + k × N 日标准差。
- **下轨**：中轨 − k × N 日标准差。

标准差反映近期波动大小，因此通道会随波动变化：波动较小时收窄，波动较大时扩张。

策略有两种交易模式：

- **突破模式（默认）**：收盘价站上上轨时买入，跌破中轨时卖出，属于顺势思路。
- **回归模式**：收盘价跌破下轨时买入，回到中轨上方时卖出，属于均值回归思路。

在股票池中，每只股票独立判断，资金等分。突破模式在震荡行情中可能遇到假突破；回归模式在单边下跌中可能反复买入。布林带也不能保证极端行情会落在通道范围内。

## 可调参数

| 参数 | 当前值 | 含义 |
|---|---:|---|
| `window`（均线周期 N） | 20 | 中轨和标准差的计算天数。周期越长，通道通常越平滑，信号越少。范围：5–120。 |
| `num_std`（标准差倍数） | 2.0 | 决定上下轨离中轨的距离。倍数越大，通道越宽、信号越少；越小，信号越多，也更容易出现假突破。范围：0.5–4。 |
| `mode`（交易模式） | `breakout` | `breakout` 为突破模式；`reversion` 为回归模式。 |
| `position_ratio`（总仓位比例） | 1.0 | 股票池等分资金后，每只股票资金槽位的使用比例。取值大于 0 且不超过 1。 |
| `stop_loss`（止损比例） | 0.0 | 相对开仓信号日收盘价的亏损达到该比例时离场；0 表示关闭。范围：0–0.5。 |
| `take_profit`（止盈比例） | 0.0 | 相对开仓信号日收盘价的盈利达到该比例时离场；0 表示关闭。范围：0–5。 |

以上是策略参数定义和当前设置，不代表参数调整后的回测效果。

## 海龟交易法则的原理

海龟交易法则是一种**期货趋势跟踪、通道突破**策略。它不试图预测价格何时见顶或见底，而是等待价格突破一段时间内的高点或低点，再顺势入场。

日线版本的基本规则是：

1. 收盘价突破入场通道后，次日开盘入场。
2. 按波动率设定止损：规则中以 **2N** 作为初始止损距离；价格朝有利方向移动时，可按 **0.5N** 间隔加仓。
3. 收盘价跌破离场通道，或触及止损后，次日开盘平仓。
4. 对单品种的总仓位设上限。这里的 **N** 可理解为衡量市场波动幅度的指标，作用是让止损和仓位管理考虑不同品种、不同波动环境。

## 适合什么行情？

更适合**有持续方向性、趋势延续较明显**的行情：突破后价格能继续沿趋势运行时，策略有机会通过持仓和加仓捕捉较大的趋势段。

在**横盘震荡、反复假突破**的行情中表现往往更困难：价格可能刚突破通道就掉头，造成连续止损。海龟策略通常依赖少数较大的趋势盈利弥补多次小亏损，因此胜率未必高；平台知识库给出的典型范围是 **30%~40%**，但这不是每次回测或每个品种的保证值。

**简单理解：**它愿意用多次小亏损，等待少数能走远的趋势；优势在趋势行情，主要弱点是假突破频繁的震荡行情。
