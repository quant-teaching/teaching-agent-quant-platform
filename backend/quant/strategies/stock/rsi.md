# RSI 超买超卖

> 股票 · 均值回归 · 经典震荡指标

## 原理

相对强弱指数（RSI，Relative Strength Index）衡量一段时间内上涨力量占总力量的比例：

```
平均涨幅 = 过去 N 日上涨幅度的威尔德平滑
平均跌幅 = 过去 N 日下跌幅度的威尔德平滑
RSI = 100 − 100 / (1 + 平均涨幅 / 平均跌幅)
```

RSI 在 0~100 之间。传统解读：

- RSI < 30：**超卖**，短期跌得太多，可能反弹；
- RSI > 70：**超买**，短期涨得太多，可能回调。

## 交易规则

1. RSI 从下方**上穿**超卖阈值（如从 28 回升到 31）时买入——等待超卖后的回升确认，而不是一进入超卖区就买；
2. RSI 高于超买阈值时卖出；
3. 可选止损和止盈。

## 参数说明

| 参数 | 默认值 | 含义 | 调参影响 |
|---|---|---|---|
| period RSI 周期 | 14 | 平滑天数 | 越短 RSI 波动越大，越容易进入超买超卖区 |
| oversold 超卖阈值 | 30 | 上穿时买入 | 调低（如 20）信号更少但反弹概率更高 |
| overbought 超买阈值 | 70 | 高于时卖出 | 调高让盈利单拿得更久 |
| position_ratio 总仓位比例 | 1.0 | 满仓比例 | — |
| stop_loss / take_profit | 0（关闭） | 止损 / 止盈 | 建议设置止损应对持续下跌 |

## 适用场景

- 区间震荡、没有明确趋势的行情；
- 大盘蓝筹等波动相对规律的股票。

## 局限性

- **强趋势中失效**：单边上涨时 RSI 可以长期处于 70 以上，过早卖出错过大部分涨幅；单边下跌时 RSI 可以长期低于 30，"超卖之后还有超卖"；
- 信号较少，样本少时回测结果的统计意义有限。

## 调参思路（教学）

- 交易次数太少：缩短 RSI 周期（如 6 或 9），或把阈值放宽到 35/65；
- 买入后继续大跌：说明处于下跌趋势，可以增加止损，或与均线趋势过滤结合（只在长期均线向上时做超卖反弹）。
