# 波动率突破

> 期货 · 波动率突破（Dual Thrust）· 经典日内策略的日线版

## 原理

Dual Thrust 由 Michael Chalek 在 1980 年代提出，曾是最受欢迎的期货日内策略之一。它用近几天的价格波幅设定当天的突破区间：

```
HH = N 日最高价的最高值    LC = N 日收盘价的最低值
HC = N 日收盘价的最高值    LL = N 日最低价的最低值
Range = max(HH − LC, HC − LL)

上轨 = 当日开盘价 + K1 × Range
下轨 = 当日开盘价 − K2 × Range
```

Range 同时考虑了最高最低价和收盘价，比简单的高低价差更稳健。以当日开盘价为基准，意味着每天的通道都会根据开盘重新定位。K1、K2 可以不对称：K1 < K2 时更容易触发做多，适合看多的市场环境。

## 交易规则（日线版本）

原版在日内价格触及上下轨时立即成交。本平台使用日线数据，改为**收盘确认**：

1. 收盘价 > 上轨 → 次日开盘做多；
2. 收盘价 < 下轨 → 次日开盘做空；
3. 持仓直到出现反向突破（多空停止反转，始终在市场中）。

## 参数说明

| 参数 | 默认值 | 含义 | 调参影响 |
|---|---|---|---|
| n 波幅回看天数 | 4 | 计算 Range 的天数 | 越长 Range 越大、突破越难 |
| k_up 上轨系数 K1 | 0.5 | — | 越小越容易做多 |
| k_down 下轨系数 K2 | 0.5 | — | 越小越容易做空 |
| position_limit 单品种仓位上限 | 0.2 | 名义市值占比 | — |
| allow_short 允许做空 | 开启 | — | — |
| stop_loss / take_profit | 0（关闭） | 止损 / 止盈 | 停止反转系统可加止损控制单次亏损 |

## 适用场景

- 波动率较大、日内趋势明显的品种；
- 突发事件导致的单日大幅波动。

## 局限性

- 日线版本丢失了原版"盘中触发"的时效性，收盘确认后次日开盘才成交，可能已错过大部分波动；
- 停止反转系统始终持仓，震荡市中会频繁反手。

## 调参思路（教学）

- 设置 K1 ≠ K2，观察多空交易次数的变化，理解非对称参数如何表达方向偏好；
- 加入止损后对比最大回撤，理解"始终在场"的系统为什么需要额外的风险控制。
