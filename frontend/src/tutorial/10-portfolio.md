# 组合实验室：把策略组合起来

## 为什么要组合

俗话说"不要把鸡蛋放在一个篮子里"。不同策略在不同行情下各有输赢：趋势策略在单边行情里赚钱、在震荡市里亏钱，均值回归策略往往正好相反。把它们放在一起，一个亏的时候另一个可能在赚，**整体的回撤就会变小**。

> [!KEY] 组合的关键是"不同步"
> 两个策略的收益**相关性越低**，组合起来分散风险的效果越好。两个几乎同涨同跌的策略，组合了也没什么用。

## 操作步骤

1. 打开 **「组合实验室」**；
2. 在「快速组合」里点一个预设，比如 **「趋势 + 动量（股票）」**，或者点「添加子策略」自己挑；
3. 打开 **「等权」** 开关就平均分配资金，关掉可以给每个子策略填权重；
4. 选择 **组合再平衡**：不调仓 / 每月 / 每季度（定期把各部分资金拉回目标比例）；
5. 点 **「开始组合回测」**。

## 怎么看组合报告

组合报告比单策略多一个 **「组合分析」** 标签：

| 内容 | 看什么 |
|---|---|
| 子策略表现 | 每个子策略单独的收益、回撤、夏普 |
| 收益相关系数 | 子策略两两之间的相关性，越接近 0 越好 |
| 分散化效果 | 组合波动率是否低于子策略的加权平均波动率 |

> [!TIP] 一个经典对比
> 分别回测"海龟交易法则"和"均值回归"两个期货策略，再把它们等权组合。比较三条净值曲线的最大回撤，你会直观地看到分散化的作用。
