# 逛算法库：读懂一个策略

## 算法库首页

点侧边栏 **「算法库」**，顶部横幅显示策略总数和可调参数总数，下面是策略卡片：

- 顶部按钮筛选 **全部 / 股票 / 期货 / 我的衍生策略**；
- 右上角搜索框可以搜名称、风格或别名，比如输入"趋势""均值回归""MACD"；
- 卡片上能看到策略风格、一句话简介、参数个数和默认标的。

## 策略详情页的三个标签

点开任意一张卡片，进入策略详情页：

| 标签 | 内容 |
|---|---|
| 教学说明 | 像这本笔记一样的格子纸文档：原理、交易规则、适用行情、局限性 |
| 参数 | 所有可调参数，带默认值、取值范围和说明，可以直接修改 |
| 源码 | 策略的 Python 源代码，想深入了解实现的同学可以看 |

右上角还有两个按钮：**「问助手」** 会带着问题跳到对话页，**「用当前参数回测」** 会把你在参数页填的值带到回测实验室。

## 怎样读一篇教学说明

建议按这个顺序读，每读完一段问自己一个问题：

1. **原理**：这个策略赚的是什么钱？（趋势的钱？回归的钱？）
2. **交易规则**：什么条件买？什么条件卖？买多少？
3. **参数**：每个参数调大调小会怎样？
4. **适用场景与局限**：什么行情下它会失效？

> [!KEY] 读懂一个策略的标准
> 能用自己的话向同学讲清楚"它什么时候买、什么时候卖、为什么这样能赚钱、什么时候会亏钱"，就算真正读懂了。

## 衍生策略

在参数页改好参数后，点 **「另存为衍生策略」**，起个名字，它就成了你自己的策略，出现在「我的衍生策略」里，对话中也能按名字调出来。
