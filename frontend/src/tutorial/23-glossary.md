# 名词速查表

遇到不懂的词，来这里查。按出现的场景分类。

## 市场与交易

| 名词 | 解释 |
|---|---|
| A 股 | 在上海、深圳、北京证券交易所上市，以人民币交易的股票 |
| 一手 | A 股买入的最小单位，100 股 |
| T+1 | 今天买入的股票明天才能卖出 |
| 涨跌停 | 每天涨跌幅的上限，主板 10%，创业板（2020-08-24 后）和科创板 20% |
| 停牌 | 公司股票暂停交易 |
| 佣金 | 交给券商的交易手续费 |
| 印花税 | 卖出股票时交给国家的税 |
| 滑点 | 实际成交价与预期价格的差距 |
| 指数 | 一篮子股票的加权平均价格，如沪深 300 |
| 基准 | 用来比较策略好坏的参照物，通常是指数 |
| 分红 / 除息 | 公司把利润以现金发给股东；发放那天股价相应下调 |
| 送转 | 送股或转增股本，股数增加、股价相应下调 |
| 复权 | 调整历史价格，消除分红送股造成的价格断崖 |
| 做多 | 先买后卖，价格上涨赚钱 |
| 做空 | 先卖后买，价格下跌赚钱（期货可以） |

## 期货

| 名词 | 解释 |
|---|---|
| 期货合约 | 约定将来按某价格买卖某商品的合约 |
| 合约乘数 | 每手合约对应的商品数量，如螺纹钢 10 吨 / 手 |
| 名义市值 | 价格 × 合约乘数 × 手数，代表实际的风险敞口 |
| 保证金 | 买卖期货需要交的押金，约为名义市值的 8%~15% |
| 杠杆 | 名义市值 ÷ 保证金，放大盈亏 |
| 主力合约 | 某品种中成交最活跃（持仓量最大）的合约 |
| 换月 / 移仓 | 主力合约切换时，把持仓从旧合约移到新合约 |
| 跳（最小变动价位） | 价格每次变动的最小单位 |

## 指标与策略

| 名词 | 解释 |
|---|---|
| 均线（MA / SMA） | 过去 N 天收盘价的平均值 |
| 指数均线（EMA） | 越近的价格权重越大的平均值 |
| 金叉 / 死叉 | 快线上穿 / 下穿慢线 |
| 标准差 | 数据离平均值的分散程度 |
| 布林带 | 均线 ± k 倍标准差构成的通道 |
| RSI | 0~100，衡量涨跌力量对比 |
| MACD | 快慢 EMA 之差（DIF）及其平滑线（DEA） |
| KDJ | 收盘价在近期高低区间中的位置 |
| ATR | 平均真实波幅，衡量每天的平均波动 |
| 动量 | 过去一段时间的涨幅 |
| Z 值 / Z 分数 | (数值 − 平均值) ÷ 标准差，表示偏离了几个标准差 |
| 趋势跟踪 | 顺着已经出现的趋势交易 |
| 均值回归 | 押注偏离的价格回到平均水平 |
| 截面 | 同一时间点上不同股票之间的比较 |
| 因子 | 能解释股票收益差异的特征，如动量、股息率 |
| 止损 / 止盈 | 亏损 / 盈利达到一定程度时离场 |
| 再平衡 | 定期把各部分资金调回目标比例 |
| 衍生策略 | 平台里"基础策略 + 修改过的参数"另存的策略 |

## 回测与评价

| 名词 | 解释 |
|---|---|
| 回测 | 用历史数据模拟策略交易 |
| 净值 | 总资产 ÷ 初始资金，起点为 1 |
| 总收益率 | 期末净值 ÷ 期初净值 − 1 |
| 年化收益率 | 换算成平均每年的复合收益 |
| 回撤 / 最大回撤 | 从之前最高点下跌的幅度 / 其中最深的一次 |
| 波动率 | 收益涨跌幅度的大小（标准差） |
| 夏普比率 | 每承担一份波动换来的超额收益 |
| 索提诺比率 | 只把下跌波动算作风险的夏普比率 |
| 卡玛比率 | 年化收益 ÷ 最大回撤 |
| 胜率 | 盈利交易笔数 ÷ 总交易笔数 |
| 盈亏比 | 平均盈利 ÷ 平均亏损 |
| 利润因子 | 盈利总额 ÷ 亏损总额 |
| 换手率 | 成交金额相对资产的倍数 |
| 阿尔法（α） | 扣除跟随大盘的部分后，额外获得的收益 |
| 贝塔（β） | 策略相对大盘的敏感度 |
| 信息比率 | 超额收益的稳定性 |
| 相关系数 | −1~1，衡量两个收益序列同涨同跌的程度 |
| 未来函数 | 回测中用到了当时还不知道的信息 |
| 幸存者偏差 | 只用存活下来的样本导致结论偏乐观 |
| 过拟合 | 参数过度贴合历史数据，把噪音当规律 |
| 样本内 / 样本外 | 用来选参数的数据 / 用来检验的数据 |
