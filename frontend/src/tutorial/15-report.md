# 读一份完整的回测报告

> [!KEY] 本章你将学到
> - 报告的整体结构
> - 净值曲线、回撤曲线和基准对比怎么看
> - 交易明细里三张表的区别
> - 用 8 问清单读完一份报告

前面几章分别讲了指标和诊断，这一章带你从上到下完整地读一遍报告，并给出一个"读报告清单"。

## 报告的整体结构

| 区域 | 内容 |
|---|---|
| 头部 | 策略名、类别标签、回测区间、标的、初始资金 → 期末资金、累计现金分红、参数标签（改过的参数高亮）、「导出数据」按钮 |
| 提示框（有时出现） | 尚未上市、停牌、参数被修正等提醒 |
| 指标卡片 | 十个核心指标，每个附沪深 300 对比 |
| 收益与回撤 | 净值曲线、回撤曲线、与基准对比、年度收益、月度收益热力图 |
| 组合分析（组合回测才有） | 子策略表现、相关系数、分散化效果 |
| 交易点位 | K 线图与买卖点 |
| 交易明细 | 每笔交易、每笔成交、按日查看持仓 |
| 诊断分析 | 行情分段、主要回撤、交易行为、盈亏贡献 |
| 底部 | 免责声明 |

## 「收益与回撤」标签页

![收益与回撤：净值曲线与回撤曲线](/tutorial/report.jpg)

### 净值曲线

- 粗线是策略，起点统一为 1.00；细线是沪深 300 等基准；
- **点击图例**可以显示 / 隐藏某条曲线；
- **拖动下方滑块**或滚动鼠标滚轮缩放时间范围；
- **点击曲线上的某一天**，会弹出当天的持仓明细。

看净值曲线时问自己：策略在哪些时间段跑赢了基准？哪些时间段跑输？曲线是平稳上升还是大起大落？

### 回撤曲线

每一天离之前最高点跌了多少。曲线越"浅"越好；看最深的地方在什么时候、持续了多久。

### 与基准对比

一张表列出策略和每个基准的同口径指标，以及**超额收益、阿尔法、贝塔、信息比率**：

| 指标 | 含义 |
|---|---|
| 年化超额收益 | 策略年化收益 − 基准年化收益 |
| 贝塔 | 基准涨 1%，策略平均涨多少；大于 1 说明比大盘更"猛" |
| 阿尔法 | 扣除"跟着大盘涨跌"的部分后，策略额外赚到的收益 |
| 信息比率 | 超额收益的稳定性，类似"超额收益的夏普比率" |

### 年度收益与月度收益

- **年度收益柱状图**：每年策略和基准各赚了多少；
- **月度收益热力图**：每一格是一个月，红色赚、绿色亏，颜色越深幅度越大。一眼就能看出策略在哪些月份集中亏损。

## 「交易明细」标签页

| 表格 | 每一行是 |
|---|---|
| 交易记录 | 一笔完整交易：方向、开仓日、平仓日、开仓均价、平仓均价、持仓天数、盈亏 |
| 成交明细 | 一次成交：日期、动作（买入 / 卖出 / 开多 / 平空 / 移仓 / 分红 / 送转）、数量、价格、手续费 |
| 持仓明细 | 选择某一天，查看当天持有哪些标的、各占多少仓位，可以按前一天 / 后一天翻看 |

报告里的成交明细最多显示一部分，完整数据可以通过「导出数据」下载。

## 读报告清单

每读一份报告，按这个顺序回答 8 个问题：

1. **赚了吗？** 年化收益率是多少？
2. **比大盘好吗？** 和沪深 300 比，年化超额收益是正还是负？
3. **过程难熬吗？** 最大回撤多深？持续多久？
4. **性价比如何？** 夏普比率和卡玛比率是多少？
5. **交易像什么样？** 胜率和盈亏比各是多少？是"高胜率小赚"还是"低胜率大赚"？
6. **成本高吗？** 交易成本占比和年化换手是多少？
7. **什么行情赚钱？** 诊断分析里上涨、下跌、震荡月分别表现如何？
8. **钱从哪来？** 盈利集中在哪些标的？亏损最多的是谁？

> [!KEY] 一句话总结
> 读完清单后，试着用一句话总结这份报告，比如："该策略 4 年年化 6.2%，跑赢沪深 300 约 8 个百分点，但最大回撤 −24%，利润主要来自上涨月，震荡月平均亏损 0.8%。"

> [!TRY] 动手试试
> 选一份你跑过的报告，按清单逐条回答，最后写出一句话总结：[打开回测记录](/history)

## 自测题

先自己想一想，再点开答案核对。

**1. 贝塔等于 1.5 是什么意思？**

> [!ANSWER]
> 沪深 300 涨 1% 时，策略平均涨约 1.5%；跌 1% 时平均跌约 1.5%。策略比大盘波动更剧烈。

**2. 想知道某一天策略持有哪些股票，有哪两种方法？**

> [!ANSWER]
> ① 在净值曲线上点击那一天；② 在「交易明细」标签页的持仓明细里选择日期。

**3. 月度收益热力图上一整列都是绿色说明什么？**

> [!ANSWER]
> 说明每年的这个月份策略都在亏钱，可以进一步分析是否和某种季节性行情有关。
