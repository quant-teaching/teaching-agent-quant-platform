# 回测记录、报告与数据导出

## 回测记录

不管是在对话里、回测实验室还是组合实验室跑的回测，都会自动保存在 **「回测记录」** 里：

- 顶部横幅显示你一共做了多少次回测，其中多少次来自智能助手；
- 表格可以按总收益率、年化收益、最大回撤、夏普等**点击表头排序**；
- 带「对话」小标签的是在聊天中生成的；
- 点击任意一行打开完整报告，右侧垃圾桶可以删除。

## 报告里的实用功能

- **查看某一天的持仓**：在净值曲线上点击任意一天，会弹出当天持有哪些股票、各占多少仓位；在「交易明细」页下方的持仓明细里，也可以选日期或按前一天 / 后一天翻看；
- **缩放时间范围**：拖动净值曲线下方的滑块，或者用鼠标滚轮缩放；
- **显示 / 隐藏曲线**：点击图例可以关掉某条基准曲线；
- **分享报告**：报告页的网址可以直接发给同学或老师查看。

## 导出原始数据

报告右上角的 **「导出数据」** 会下载一个 zip 压缩包，里面有：

| 文件 | 内容 |
|---|---|
| 说明.txt | 策略、参数、成本设置和免责声明 |
| 量化指标.csv | 全部指标，以及和各基准的对比 |
| 每日净值.csv | 每天的净值、回撤、仓位 |
| 年度收益.csv / 月度收益.csv | 分期收益 |
| 交易记录.csv | 每一笔完整交易（开仓到平仓） |
| 成交明细.csv | 每一笔成交，包括分红、送转记录 |
| 持仓明细.csv | 每天收盘的持仓 |

CSV 文件可以直接用 Excel 打开，适合写实验报告或做进一步分析。

> [!TIP] 在对话里也能要数据
> 对助手说"把这次回测的每日净值和交易记录原始数据给我"，它会告诉你数据集的内容和下载方式。
