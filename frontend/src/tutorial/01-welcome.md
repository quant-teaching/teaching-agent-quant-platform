# 欢迎来到量化策略教学平台

这套教程写给**完全没接触过量化、甚至没买过股票**的同学。跟着从头读到尾，你会知道：量化交易是什么、回测是怎么回事、报告里那些指标怎么看，最后能独立用这个网站完成"选策略 → 改参数 → 回测 → 分析 → 优化"的完整流程。

> [!KEY] 一句话认识这个平台
> 这是一个**教学实验室**：你用大白话告诉智能助手想做什么，它会从算法库调出经典策略、按你的要求改参数，再用 2016 年以来的真实历史行情模拟交易，最后把结果画成图表、讲给你听。

## 平台里有什么

| 模块 | 能做什么 | 适合什么时候用 |
|---|---|---|
| 智能助手 | 用自然语言调策略、改参数、回测、问概念 | 不知道从哪下手时，先来这里聊 |
| 算法库 | 22 个经典策略，每个都有原理、参数和源码 | 想系统地了解某个策略 |
| 回测实验室 | 手动选策略、填参数、跑回测 | 想自己精细地调参数 |
| 组合实验室 | 把多个策略按比例组合在一起回测 | 学习分散投资 |
| 回测记录 | 所有跑过的回测都存在这里 | 回看、对比、导出数据 |

## 这套教程怎么读

1. **准备出发**（2 章）：认识平台、学会登录和找到各个功能；
2. **量化零基础**（4 章）：K 线、均线、回测、指标，量化的"基本功"；
3. **动手实操**（5 章）：每一章都带你在网站上真正做一遍；
4. **进阶与避坑**（4 章）：参数优化、期货、回测陷阱和常见问题。

每章大约 5~10 分钟。读完一章点底部的**「我学会了」**，左侧目录会打勾，顶部进度条会前进。

> [!TIP] 边读边做
> 看到粉色虚线框的「动手试试」，就点里面的按钮直接跳到对应页面操作。做过一遍，比读三遍记得牢。

> [!WARNING] 先记住这条
> 平台里的所有回测都是**用历史数据做的模拟**，只用于学习算法原理。历史表现不代表未来，平台也不会给出"买哪只股票"之类的实盘建议。
