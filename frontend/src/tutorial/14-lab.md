# 回测实验室：自己调参数

> [!KEY] 本章你将学到
> - 参数栏七个部分分别是什么
> - 交易成本与风控里的各项设置
> - 完成一次控制变量的调参练习
> - 常见提示的含义

如果你想精确控制每一个设置，回测实验室比对话更直接。

![回测实验室：左侧参数栏，右侧回测报告](/tutorial/lab.jpg)

## 左侧参数栏，从上到下

### 1. 策略

下拉选择策略，可以输入文字搜索。选中后下方显示一句话简介。

### 2. 标的

| 方式 | 说明 |
|---|---|
| 预设标的池 | 教学股票池（55 只）、申万一级行业（31 个）、商品期货（16 个品种）等，选项和策略类型有关 |
| 自选标的 | 自己挑选几只股票或期货，可以输入名称或代码搜索 |

### 3. 回测区间

起止日期。右上角会提示数据范围（股票 2016 年起、期货 2020 年起）。

### 4. 初始资金

单位是**万元**，默认 1000 万。资金太少时（比如 10 万元买 55 只股票），每只股票分到的钱可能买不够 100 股，回测结果会失真。

### 5. 对比基准

沪深 300、中证 500、创业板指，可以多选，会叠加画在净值曲线上。

### 6. 交易成本与风控

点开后可以修改：

| 设置 | 默认值 | 说明 |
|---|---|---|
| 股票佣金率 | 万分之 2.5 | 双向收取，单笔最低 5 元 |
| 股票滑点 | 0.05% | 成交价偏离开盘价的比例 |
| 期货手续费倍数 | 1 | 相对各品种默认费率的倍数 |
| 期货滑点 | 1 跳 | 最小价格变动单位的个数 |
| 保证金占用上限 | 80% | 期货保证金不超过权益的比例 |
| 无风险利率 | 0 | 用于计算夏普比率 |

### 7. 策略参数

每个参数都有中文名，**鼠标停在名字上会显示详细说明**。改过的参数会高亮，改乱了可以点右上角「恢复默认」一次全部还原。

填好后点最下面的蓝色按钮 **「开始回测」**，右侧就会出现完整报告，同时自动保存到回测记录。

## 一个完整的调参练习

> [!TRY] 跟着做：短均线周期对双均线策略的影响
> 1. 打开 [回测实验室](/backtest)，策略选 **双均线策略**，其他保持默认，点「开始回测」；
> 2. 在下面的表格里记下年化收益、最大回撤、夏普比率、交易次数、交易成本；
> 3. 把「短均线周期」从 10 改成 5，再回测一次，记录；
> 4. 再改成 20，回测第三次，记录；
> 5. 到 [回测记录](/history) 里把三次结果放在一起看。

| 短均线 | 年化收益 | 最大回撤 | 夏普 | 交易次数 | 交易成本 |
|---:|---:|---:|---:|---:|---:|
| 5 | | | | | |
| 10 | | | | | |
| 20 | | | | | |

做完之后思考：

1. 短均线越短，交易次数是变多还是变少？交易成本呢？
2. 哪个参数的最大回撤最小？收益最高的那个，回撤也最小吗？
3. 三组结果差别大吗？如果差别很小，说明这个参数"不敏感"，这是好事还是坏事？

> [!TIP] 一次只改一个参数
> 同时改好几个参数，就分不清结果的变化是谁造成的。科学的做法是"控制变量"：其他条件都不变，每次只动一个。第 21 章会系统地讲实验方法。

## 从算法库跳过来

在策略详情页的「参数」标签里改好参数，点 **「用当前参数回测」**，会自动打开回测实验室并带上这个策略和参数，直接点「开始回测」即可。

## 常见提示

| 提示 | 原因 |
|---|---|
| 短均线周期必须小于长均线周期 | 参数之间有大小关系的约束 |
| 区间内交易日不足 | 日期不在数据范围内，期货策略常见于开始日期早于 2020 年 |
| 报告顶部黄色提示"以下标的在回测开始时尚未上市或停牌" | 这些标的有数据后才开始交易，属于正常情况 |
| A 股不能直接做空，股票的负权重已按 0 处理 | 股票只能做多 |

> [!WARNING] 小心"调过头"
> 如果你一直调参数，直到某组参数在这段历史里表现完美，那很可能只是碰巧适合这段历史。第 20 章「参数优化与过拟合」会专门讲怎么避免。

## 本章小结

- 回测实验室能精确控制策略、标的、区间、资金、基准、成本和参数；
- 调参时一次只改一个参数，并把结果记录下来比较；
- 看到"区间内交易日不足"先检查日期是否在数据范围内。

## 自测题

先自己想一想，再点开答案核对。

**1. 想让回测更接近"零成本"的理想情况，应该改哪里？**

> [!ANSWER]
> 在「交易成本与风控」里把佣金率和滑点调为 0。这样可以观察成本对策略的影响有多大。

**2. 期货策略开始日期设为 2018-01-01 会怎样？**

> [!ANSWER]
> 期货数据从 2020 年 1 月开始，会提示区间内交易日不足或只从有数据的日期开始交易。

**3. 为什么不建议同时改多个参数？**

> [!ANSWER]
> 同时改多个参数，就分不清结果的变化是哪个参数造成的。
