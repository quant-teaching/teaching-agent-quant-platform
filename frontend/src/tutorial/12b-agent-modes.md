# 谁来做决定：智能体的四种工作模式

> [!KEY] 本章你将学到
> - 自动执行、每步确认、先计划后执行、自主研究四种模式的区别
> - 怎样批准、修改或拒绝智能体的一步操作
> - 怎样审核和修改智能体的计划
> - 怎样限定智能体能用的工具、策略和回测次数

前面几章里，智能助手一收到问题就自己决定调用哪些工具、用什么参数。这很方便，但学习时你往往想**自己做主**：这一步该不该做？参数是不是我想要的？平台把"谁来做决定"交给你选择。

## 在哪里切换

输入框右下角、模型选择的左边，有一个写着当前模式的按钮（默认是「自动执行」）。点开它：

![点开模式按钮，选择谁来做决定](/tutorial/modes-picker.png)

| 模式 | 谁做决定 | 适合什么时候 |
|---|---|---|
| 自动执行 | 智能体 | 熟悉平台以后，想快速得到结果 |
| 每步确认 | 你逐步把关 | 想看清智能体每一步要做什么，随时纠正 |
| 先计划后执行 | 你定方案 | 想先看完整思路，自己调整后再动手 |
| 自主研究 | 智能体自主探索 | 给出一个研究目标，让智能体自己设计实验、反思、迭代 |

选好以后会记在你的浏览器里，下次打开还是这个模式。

## 每步确认：每一步都由你批准

智能体每次准备调用工具（调取策略、修改参数、回测……）时都会**先停下来**，弹出一张确认卡片：

![确认卡片：可以批准、拒绝或修改参数](/tutorial/modes-confirm.png)

- **批准**：照智能体的想法执行；
- **拒绝**：这一步不执行。可以在下方写一句理由，比如"先不要改参数，用默认参数回测"，智能体会根据你的意见调整；
- **修改参数**：展开参数表单，直接改，比如把回测结束日期改成 2023-06-30、把长均线改成 40；
- **全部拒绝 / 确认并继续**：提交你的决定，智能体接着往下做，下一次要调用工具时会再停下来问你。

> [!NOTE]
> 卡片没确认就发了新消息，这张卡片会自动作废；刷新页面不影响，还没确认的卡片仍然可以操作。

## 先计划后执行：先看方案再动手

智能体先写一份计划（这时它**不能**调用任何工具），交给你审核：

![计划卡片：可以调整顺序、修改参数、删除或添加步骤](/tutorial/modes-plan.png)

你可以：上下移动步骤、修改每一步的参数、删除不需要的步骤，或在下拉框里**添加一步**。点「按计划执行」后，由**程序**严格按你确认的步骤逐一执行，智能体最后只负责分析结果；点「取消计划」则什么都不执行。

> [!TIP]
> 这个模式很适合练习"实验设计"：先想清楚要做哪几个对照实验，再看结果。

## 自主研究：让智能体自己探索

给出一个**研究目标**，例如：

```
研究目标：在 2022-01-01 到 2024-12-31 区间，找一组让双均线股票策略最大回撤比默认参数更小的参数，最多试两组
```

智能体会自己：

1. **制定研究计划**：重述目标、写出"怎样算达成"的标准；
2. **第 1 轮实验**：调用工具回测；
3. **反思**：用回测数字判断目标是否达成，没达成就决定下一轮做什么；
4. 重复，直到达成目标、用完迭代轮数或回测次数；
5. **写研究报告**：过程、结论、局限和你可以继续做的验证。

![自主研究：研究计划、每轮实验和反思](/tutorial/modes-research.png)

在一次真实的研究里，智能体第 1 轮换了两组均线周期，反思发现最大回撤并没有变小；第 2 轮它改为降低仓位，回撤明显减小，于是判定目标达成并写了报告。**整个过程的每一步你都看得到**，可以拿来和自己的思路对比。

> [!WARNING]
> 自主研究找到的"更好参数"同样有过拟合风险，报告里的结论只说明历史表现。把它当作下一步实验的线索，而不是答案。

## 智能体控制：限定工具、策略和回测次数

点开模式按钮，选最下面的「工具、策略范围与回测上限」，打开控制面板：

![智能体控制面板](/tutorial/modes-drawer.png)

| 设置 | 作用 | 例子 |
|---|---|---|
| 允许使用的工具 | 关掉某个工具，智能体就不能用它 | 关掉"修改参数"，强制只用默认参数 |
| 可以使用的策略 | 只允许智能体调取和回测指定的策略 | 作业要求"只用双均线和 MACD" |
| 每轮最多回测 | 一次提问最多回测几次 | 防止自主研究跑太多实验 |
| 自主研究最多迭代 | 研究最多进行几轮 | 设为 2，让它快点给结论 |

这些限制**由平台强制执行**，不是"请智能体自觉遵守"：被关掉的工具根本不会提供给智能体，它即使尝试调用范围外的策略，也只会收到拒绝。

## 本章小结

- 输入框旁的模式按钮决定"谁来做决定"：自动执行、每步确认、先计划后执行、自主研究；
- 每步确认可以批准、拒绝（附理由）或修改参数；先计划后执行可以调整、增删步骤；
- 自主研究让智能体自己计划、实验、反思、迭代，最后交研究报告；
- 控制面板能限定工具、策略范围和回测次数，由平台强制执行。

## 自测题

先自己想一想，再点开答案核对。

**1. 你想确保智能体只用默认参数回测，有哪两种做法？**

> [!ANSWER]
> 一是在控制面板里关掉「修改参数」工具；二是用「每步确认」模式，遇到修改参数的步骤时点「拒绝」。

**2. 「先计划后执行」中，计划里的步骤由谁执行？**

> [!ANSWER]
> 由程序按你确认后的计划逐步执行。智能体只负责写计划和最后分析结果，执行时不能临时增加步骤。

**3. 自主研究在什么情况下会停止？**

> [!ANSWER]
> 反思判断目标已经达成、达到最多迭代轮数、或回测次数用完，三者满足其一就停止并写研究报告。
