# 注册登录与界面导览

## 第一步：注册账号

如果你打开网站看到的是登录页，说明老师开启了账号登录：

1. 点右侧的 **「注册」** 标签；
2. 填写**用户名**（2~20 位中文、字母、数字或下划线）；
3. 设置**密码**：8 位以上，要**同时包含字母和数字**，输入时下面会实时提示是否满足；
4. 填写老师给你的**邀请码**，点「注册并登录」。

> [!NOTE] 没有邀请码？
> 邀请码由老师统一发放，用来防止陌生人随意注册。没收到就问问老师或同学。

勾选 **「30 天内自动登录」**，下次打开就不用再输密码。忘记密码请联系老师重置；登录后可以在左下角头像菜单里**修改密码**。

## 第二步：认识界面

整个网站分成两块：**左边是侧边栏**，**右边是工作区**。

- 侧边栏从上到下：智能助手、新手教程、算法库、回测实验室、组合实验室、回测记录；
- 左下角：模型设置、你的头像（修改密码 / 退出登录），以及**深色 / 浅色模式切换**按钮；
- 侧边栏底部的灰色小字是免责声明，提醒大家这里只做教学。

> [!TIP] 晚上学习护眼
> 点左下角的月亮图标切到深色模式，连这本笔记的格子纸也会变成深色。
