# 和助手高效对话的技巧

同样的需求，说法不同，得到的结果可能差很多。这一章是一份"说话手册"。

## 一个好的回测请求包含什么

| 要素 | 说法示例 | 不说会怎样 |
|---|---|---|
| 策略 | "双均线策略""海龟""动量选股" | 助手会先问你想用哪个策略 |
| 时间 | "2021-01-01 到 2024-12-31" | 使用默认区间 |
| 标的 | "沪深 A 股""商品期货""申万行业""600519" | 使用策略的默认标的 |
| 参数 | "ATR 周期改为 22，仓位上限 0.15" | 使用默认参数或当前会话中改过的参数 |
| 要求 | "对比沪深 300""分析震荡市表现" | 助手按通用结构分析 |

**完整示例**：

```
调出海龟交易期货策略，把 ATR 周期改为 22，单笔仓位上限 0.15，回测 2021-01-01 到 2024-12-30，标的选择国内商品期货主力合约
```

## 常用句式速查

### 学习类

| 想做什么 | 推荐说法 |
|---|---|
| 了解策略原理 | "给我讲下布林带股票策略原理，它的可调参数是什么" |
| 问概念 | "什么是夏普比率？用一个例子解释" |
| 比较策略 | "双均线和 MACD 有什么区别？" |
| 查数据范围 | "平台的期货数据从什么时候开始？" |

### 回测类

| 想做什么 | 推荐说法 |
|---|---|
| 基础回测 | "用 RSI 策略回测沪深 A 股 2022-01-01 到 2025-12-31" |
| 改参数再测 | "把超卖阈值改成 25，再回测一次" |
| 参数敏感性 | "短均线周期分别取 5、10、20，对比效果" |
| 组合回测 | "把双均线和动量选股做等权组合，回测 2022-01-01 至 2025-06-30" |
| 恢复默认 | "把海龟策略的参数恢复默认" |

### 分析与优化类

| 想做什么 | 推荐说法 |
|---|---|
| 解读报告 | "分析一下这次回测的主要亏损来源" |
| 问原因 | "为什么 2024 年回撤这么大？" |
| 要优化建议 | "给我一个具体的参数优化建议，并实际验证一下效果" |
| 保存参数 | "把这组参数保存成衍生策略，叫'慢速双均线'" |
| 要原始数据 | "把这次回测的每日净值和交易记录原始数据给我" |

## 多轮对话的技巧

1. **先粗后细**：先用默认参数跑一次，看完报告再决定改什么；
2. **一次改一个**：每次只让助手改一个参数，才能看清楚这个参数的作用；
3. **要求对比**：改完参数后说"和上一次对比"，助手会把两次结果放在一起分析；
4. **追问"为什么"**：助手给出结论后，追问"为什么""依据是什么"，它会引用诊断数据。

## 选择模型

对话页右上角的按钮可以选择用哪个大模型来回答：

![模型选择：自动，以及按渠道分组的模型列表](/tutorial/model-picker.jpg)

| 选项 | 说明 |
|---|---|
| **自动**（推荐） | 使用老师在「模型设置」里配置的主模型；主模型失败时自动切换到备用模型 |
| 指定某个模型 | 从列表中选择某个渠道下的具体模型；如果它调用失败，仍会按主备顺序兜底 |

- 列表按**渠道**分组，可以在顶部搜索框里输入模型名或渠道名筛选；
- 你的选择会记在这台电脑的浏览器里，下次打开仍然有效；
- 回复下方会显示这一轮实际使用的模型；如果发生了切换，对话中会提示"已自动切换到备用模型"。

> [!NOTE] 不同模型有什么区别
> 回测数字由引擎计算，和模型无关；不同模型的区别主要在**解读和表达**：有的更详细、有的更简洁，有的速度更快。可以用同一个问题试试不同的模型，体会它们的差别。

## 助手出错了怎么办

| 现象 | 处理方法 |
|---|---|
| 步骤标签变成红色 ✕ | 点开看错误原因，常见的是参数超出范围或日期不在数据范围内，助手通常会自动修正后重试 |
| 显示"未配置模型" | 请联系老师在模型设置中配置 |
| 回答很久没有反应 | 点输入框右侧的红色方块停止，再重新发送；或换一个模型 |
| 数据核验提示有未核验的数字 | 说明回复中有数字没在工具结果中找到，可以让助手说明来源 |
