# 学习路线与实验报告

> [!KEY] 本章你将学到

## 四周学习路线

### 第 1 周：入门

- 读完本教程第一、二部分（第 1~10 章）；
- 用智能助手的示例卡片跑 3~5 个不同策略的回测；
- 目标：能看懂报告里的每一个指标。

### 第 2 周：吃透一个策略

- 选双均线或动量选股，读懂算法库里的教学说明，跟着例子手算一遍指标；
- 在回测实验室里逐个参数做对比实验，填写实验记录表；
- 目标：能讲清楚这个策略的每个参数有什么作用。

### 第 3 周：学会分析

- 重点读「诊断分析」，说清楚策略在上涨、下跌、震荡月分别表现如何；
- 让助手给出优化建议并验证，判断建议是否合理；
- 用样本内 / 样本外分段的方法检验一次参数；
- 目标：能写出有数据支撑的分析结论。

### 第 4 周：组合与期货

- 做一次组合回测，分析相关系数和分散化效果；
- 尝试一个期货 CTA 策略，理解做空、杠杆和换月；
- 完成一份完整的实验报告；
- 目标：独立完成一次完整的量化研究。

### 之后

- 读策略源码，理解规则是怎么变成程序的；
- 用衍生策略保存你自己的参数方案；
- 比较同一类型的不同策略（比如四个"通道突破"类期货策略）。

## 实验报告模板

学完之后，可以按这个结构写一份实验报告：

| 部分 | 内容 | 篇幅建议 |
|---|---|---|
| 1. 研究问题 | 你想回答什么问题，为什么重要 | 一段 |
| 2. 策略介绍 | 策略原理、交易规则、关键参数 | 半页 |
| 3. 实验设置 | 标的、区间、初始资金、成本、对照组与实验组 | 一张表 |
| 4. 实验结果 | 关键指标对比表、净值曲线截图 | 一页 |
| 5. 分析 | 结合诊断数据解释结果，为什么会这样 | 一页 |
| 6. 稳健性检验 | 换区间 / 换参数 / 换标的后结论是否成立 | 半页 |
| 7. 局限 | 幸存者偏差、成本假设、样本长度等 | 一段 |
| 8. 结论 | 用两三句话回答研究问题 | 一段 |

> [!TIP] 素材从哪来
> - 指标表格：「导出数据」里的量化指标.csv；
> - 图表：报告页截图，或者用每日净值.csv 自己在 Excel 里画；
> - 分析依据：诊断分析页面，以及让智能助手解读后自己核对。

> [!WARNING] 别忘了
> 报告里要写明"回测结果仅用于教学，历史表现不代表未来，不构成投资建议"。

## 本章小结

- 按入门 → 吃透一个策略 → 学会分析 → 组合与期货的顺序推进；
- 实验报告包括问题、策略、设置、结果、分析、稳健性、局限和结论；
- 从 ★ 题目开始，逐步挑战更难的研究。
