# 老师指南：班级与学生管理

这一章写给**老师**。学生可以跳过。

> [!KEY] 本章你将学到
> - 怎样注册老师账号
> - 创建班级、分发班级邀请码
> - 用模板批量导入学生名单
> - 管理学生：改名、重置密码、停用、移班、删除、查看回测
> - 一次性注册码、学生的模型额度和使用权限
> - 班级之间是怎样隔离的

## 三种角色

| 角色 | 能做什么 |
|---|---|
| 学生 | 使用全部学习功能；只能看到自己的对话和回测，以及同班同学分享的报告 |
| 老师 | 学生能做的都能做；另外可以创建和管理**自己的**班级与学生 |
| 管理员 | 管理所有班级和账号、发放教师注册码、配置大模型接口 |

## 第一步：注册老师账号

1. 向平台管理员索取**教师注册码**；
2. 打开登录页，点「注册」，选择 **「我是老师」**；
3. 填写用户名、显示名称（如"王老师"，学生会看到）、密码，以及教师注册码。

![注册页：选择「我是学生」或「我是老师」](/tutorial/register.jpg)

> [!NOTE] 也可以由管理员直接创建
> 管理员可以在「设置 → 用户管理」里直接新建老师账号并告诉你初始密码，这样就不需要注册码。

## 第二步：创建班级

登录后打开左下角 **「设置」**，进入 **「班级管理」**：

![班级管理：顶部汇总、班级卡片和邀请码](/tutorial/teacher-classes.jpg)

1. 点右上角 **「新建班级」**，填写班级名称（如"2026 春 量化投资一班"）和备注；
2. 创建后系统自动生成一个**班级邀请码**，显示在班级卡片下方的虚线框里；
3. 一位老师可以创建多个班级，每个班级的邀请码、学生、统计数据都是独立的。

每张班级卡片上能看到：

| 内容 | 含义 |
|---|---|
| 学生 | 班级里的学生人数 |
| 近 7 天登录 | 最近一周登录过的学生人数，下方进度条显示占比 |
| 回测次数 | 全班学生累计跑过的回测次数 |
| 邀请码 | 点复制按钮会复制"注册网址 + 邀请码"，可以直接发到班级群 |
| 开放注册 | 关掉后这个邀请码暂时不能注册新账号，已有学生不受影响 |

右上角的 **「⋯」** 菜单里可以编辑班级、更换邀请码（旧码立即失效）、删除班级（班里还有学生时不能删除）。

## 第三步：让学生进班

有两种方式，可以混用：

### 方式一：学生自己注册

把邀请码发给学生，学生在登录页选「注册 → 我是学生」，填写邀请码即可进入你的班级。学生注册完后，可以关闭「开放注册」，防止邀请码外传。

### 方式二：一次性注册码

班级详情页里有 **「一次性注册码」** 卡片：输入数量（1~200）和备注，点「生成」，得到一批形如 `K7QP-M3ZX` 的注册码。

| 对比 | 通用邀请码 | 一次性注册码 |
|---|---|---|
| 能用几次 | 反复使用，直到更换或关闭 | 每个码只能注册一个账号 |
| 适合 | 课堂上统一发到班级群 | 逐个发给学生、补录个别同学，防止外传 |
| 能否关闭 | 用班级的「开放注册」开关 | 未使用的码可以单个作废 |
| 受「开放注册」开关影响 | 是 | **否**，关闭通用码后一次性码仍然可用 |

列表里可以看到每个码的状态（未使用 / 已使用 / 已作废）以及**是谁用掉的**；可以「复制全部未使用」或「下载表格」逐个分发。

**批量管理**：生成时填写的备注就是"批次名"，可以按批次筛选、按注册码 / 备注 / 使用者搜索。勾选左侧复选框（表头可全选当前筛选结果）后，上方会出现批量操作栏：复制、导出、改备注、作废、删除。已经被使用的码会作为注册记录保留，批量作废和删除时会自动跳过。

### 方式三：批量导入名单

适合已经有学生名单的情况，学生拿到账号直接登录，不需要自己注册。

1. 点班级卡片进入班级详情，点 **「批量导入」**；
2. 点 **「下载模板」**，用 Excel 打开，按列填写：

| 用户名 | 姓名 | 初始密码 |
|---|---|---|
| zhangsan01 | 张三 | （留空自动生成） |
| lisi02 | 李四 | study2026 |

   - **用户名**必填，2~20 位中文、字母、数字或下划线，比如用学号；
   - **姓名**选填，会显示在班级名单里；
   - **初始密码**选填，留空则系统自动生成 8 位密码（字母加数字，去掉了 0/O、1/l 这类容易看错的字符）。
3. 保存后把文件拖进导入窗口（支持 .csv 和 .xlsx），系统会逐行检查：

![批量导入：预览校验，标出每一行的问题](/tutorial/teacher-import.jpg)

4. 有问题的行（用户名已存在、重复、格式不对、密码太简单）会标红，**不会导入**；确认无误后点 **「导入 N 个账号」**；
5. 导入完成后点 **「下载账号清单」**，得到一份包含用户名和初始密码的表格，发给学生。

> [!WARNING] 初始密码只显示一次
> 导入完成后请立即下载账号清单。如果忘了下载，可以在学生列表里逐个「重置密码」重新生成。

## 第四步：管理学生

班级详情页上方是 **近 30 天回测次数** 柱状图（鼠标停在柱子上可以看当天活跃人数）和几个关键数字：学生人数、近 7 天登录、从未登录、累计回测、周活跃率。

![班级详情：活跃度图表与学生列表](/tutorial/teacher-detail.jpg)

下方是学生列表，可以搜索、按回测次数或最近登录排序。每一行右侧的 **「⋯」** 菜单：

| 操作 | 说明 |
|---|---|
| 修改姓名 | 改学生的显示名称 |
| 重置密码 | 生成新的随机密码并显示给你，学生当前的登录会失效 |
| 移到其他班级 | 只能在你自己负责的班级之间移动 |
| 查看回测记录 | 右侧弹出该学生的全部回测，点击可以打开完整报告 |
| 停用 / 启用账号 | 停用后学生立即退出登录、无法再登录，数据保留 |
| 删除账号 | 删除后无法恢复，学生的回测记录保留在系统中 |

右上角还有 **「添加学生」**（单个创建）和 **「导出名单」**（导出学生名单、回测次数、最近登录时间，方便统计平时成绩）。

## 第五步：模型额度与使用权限

智能助手使用的大模型会产生费用，所以平台按**每天的对话次数**控制用量（发送一条消息算一次，每天 0 点重置）：

| 设置位置 | 谁能设置 | 作用 |
|---|---|---|
| 设置 → 用户管理 → 平台模型默认额度 | 管理员 | 所有老师 / 所有学生的默认次数 |
| 班级详情 → 学生默认额度 | 负责老师、管理员 | 本班学生的默认次数 |
| 学生列表 → ⋯ → 设置每日次数 | 负责老师、管理员 | 单个学生的次数 |

生效顺序：**个人设置 > 班级默认 > 平台默认**。学生列表的「今日用量」一栏显示"已用 / 上限"，用完时显示为红色。

「平台模型」开关可以单独关闭某个学生使用平台模型的权限。学生也可以在「设置 → 我的模型」添加**自己的模型渠道**（自己的 API Key），只有本人能看到和使用，不占平台额度；是否允许学生自建渠道由管理员在「用户管理」里控制。

## 班级隔离规则

| 谁 | 能看到什么 |
|---|---|
| 学生 | 自己的对话、回测记录、衍生策略；同班同学分享的报告链接 |
| 老师 | 自己负责的班级、这些班级的学生和他们的回测报告 |
| 其他班的老师和学生 | **看不到**你班级的任何数据，打开你班学生的报告链接会提示不存在 |
| 管理员 | 全部班级和账号 |

> [!TIP] 布置作业的一种做法
> 让学生把完成作业的回测报告链接提交给你，你直接打开就能看到完整报告；也可以在班级详情里点学生的「查看回测记录」，按时间核对每个人做了哪些实验。

## 本章小结

- 老师用教师注册码注册，或由管理员创建账号；
- 每个班级有独立的通用邀请码，也可以生成一次性注册码，或下载模板批量导入名单；
- 可以为班级和单个学生设置每日对话次数，单独关闭学生的平台模型权限；
- 班级详情页可以查看活跃度、管理学生、查看学生回测；
- 不同班级之间的数据互相隔离。

## 自测题

**1. 学生用了 A 班的邀请码注册，会进入哪个班？**

> [!ANSWER]
> A 班。邀请码决定学生所属的班级。如果进错了班，老师可以在学生列表里用「移到其他班级」调整（只能在自己负责的班级之间移动）。

**2. 批量导入时，表格里有一行用户名已经被别人注册过，会怎样？**

> [!ANSWER]
> 这一行在预览时会标红显示"用户名已存在"，不会被导入；其他没有问题的行可以正常导入。

**3. 想让邀请码失效，但不影响已经注册的学生，应该怎么做？**

> [!ANSWER]
> 关闭班级的「开放注册」开关，或者在「⋯」菜单里「更换邀请码」。两种方式都不影响已有学生。
