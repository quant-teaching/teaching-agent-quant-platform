## 策略详情页

点开任意一张卡片，进入策略详情页。顶部是策略名、标签和一句话简介，右上角有两个按钮：

- **问助手**：带着"给我讲讲这个策略的原理"跳到对话页；
- **用当前参数回测**：把参数页里填的值带到回测实验室。

下方有三个标签页：

### 教学说明

和这本教程一样的格子纸笔记，每个策略都按相同的结构编写：

| 小节 | 内容 |
|---|---|
| 一句话理解 | 用最简单的话说清楚策略在做什么 |
| 生活中的类比 | 用身边的例子帮助理解 |
| 原理 | 策略赚的是什么钱、背后的市场规律 |
| 指标怎么算 | 公式加上一个可以手算的数字例子 |
| 交易规则（平台实现） | 平台代码里实际执行的规则 |
| 参数详解 | 每个参数的默认值、范围、调大调小的影响 |
| 什么行情好用 / 吃亏 | 适用场景和局限 |
| 怎么读它的回测报告 | 这类策略的报告应该重点看什么 |
| 常见误区 | 新手容易误解的地方 |
| 动手实验 | 可以直接复制到智能助手的实验指令 |

### 参数

列出所有可调参数，可以直接修改。改过的参数会高亮显示，旁边有一个小按钮可以单独恢复成默认值。改好后可以：

- 点 **「用当前参数回测」** 去回测实验室；
- 点 **「另存为衍生策略」**，起个名字保存成你自己的策略。

### 源码

策略的 Python 源代码，带语法高亮。不会编程也没关系，可以看看注释，感受一下"规则是怎么变成程序的"。

## 怎样读懂一个策略

建议按这个顺序读，每读完一段，合上笔记问自己一个问题：

1. **一句话理解** → 我能用一句话复述吗？
2. **原理** → 这个策略赚的是趋势的钱、回归的钱，还是选股的钱？
3. **交易规则** → 什么条件买？什么条件卖？买多少？
4. **指标怎么算** → 我能跟着例子手算一遍吗？
5. **参数详解** → 哪个参数最重要？调大调小会怎样？
6. **什么行情吃亏** → 它最怕什么样的市场？

> [!KEY] 读懂一个策略的标准
> 能用自己的话向同学讲清楚"它什么时候买、什么时候卖、为什么这样能赚钱、什么时候会亏钱"，就算真正读懂了。

## 衍生策略

衍生策略 = **基础策略 + 你修改过的参数**。比如把双均线改成 20/60 后保存为"慢速双均线"：

- 它会出现在算法库「我的衍生策略」里，卡片上有「衍生」标记；
- 在回测实验室和对话中都可以按名字调用；
- 详情页会显示"基于 双均线策略"，并可以删除。
