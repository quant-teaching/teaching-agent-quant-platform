# 回测记录与数据导出

> [!KEY] 本章你将学到
> - 回测记录页的筛选、排序和删除
> - 分享报告
> - 导出数据集里的每个文件
> - 用 Excel 自己画净值曲线

## 回测记录页

不管是在对话里、回测实验室还是组合实验室跑的回测，都会自动保存在 **「回测记录」** 里。

![回测记录：顶部统计与可排序的回测列表](/tutorial/history.jpg)

| 区域 | 内容 |
|---|---|
| 顶部横幅 | 回测总数、来自智能助手的次数、最高总收益、最高夏普 |
| 筛选 | 全部 / 单策略 / 组合；按策略名搜索 |
| 表格 | 每次回测的策略、区间、总收益率、年化收益、最大回撤、夏普、卡玛、胜率、沪深 300 年化、时间 |

操作：

- **点击表头**按该列排序，比如按夏普从高到低；
- 带 **「对话」** 小标签的是在聊天中生成的；带组合图标的是组合回测；
- **点击任意一行**打开完整报告；
- 右侧**垃圾桶**图标删除这条记录（只能删除自己的）。

## 报告的分享

报告页的网址（形如 `/report/xxxxxxxx`）可以直接发给同学或老师，对方登录后就能打开查看。

## 导出原始数据

报告右上角的 **「导出数据」** 会下载一个 zip 压缩包：

| 文件 | 内容 | 适合做什么 |
|---|---|---|
| 说明.txt | 策略、参数、成本设置和免责声明 | 写实验报告时引用 |
| 量化指标.csv | 全部指标，以及和各基准的对比 | 做对比表格 |
| 每日净值.csv | 每天的净值、回撤、仓位暴露 | 自己画净值曲线 |
| 年度收益.csv / 月度收益.csv | 分期收益 | 分析季节性 |
| 交易记录.csv | 每一笔完整交易 | 统计胜率、持仓时间分布 |
| 成交明细.csv | 每一笔成交，包括移仓、分红、送转 | 核对交易过程 |
| 持仓明细.csv | 每天收盘的持仓 | 分析持仓集中度 |
| report.json | 完整的报告数据 | 用程序进一步处理 |

CSV 文件可以直接用 Excel 打开，中文不会乱码。

> [!TIP] 在对话里也能要数据
> 对助手说"把这次回测的每日净值和交易记录原始数据给我"，它会介绍数据集里有哪些内容和下载方式。

## 一个 Excel 小练习

1. 导出一份报告的数据，用 Excel 打开「每日净值.csv」；
2. 选中日期和净值两列，插入折线图——你就画出了自己的净值曲线；
3. 在旁边新建一列，用公式计算每天的涨跌幅：`=B3/B2-1`；
4. 用 `=MAX()`、`=MIN()` 找出最好和最差的一天，和报告里的数字核对。

> [!TRY] 动手试试
> 打开最近的一份报告，点净值曲线上的某一天看看当时的持仓，再导出一次数据：[打开回测记录](/history)

## 本章小结

- 所有回测都会自动保存，点表头排序、点行打开报告；
- 报告网址可以直接分享；
- 导出的 zip 包含指标、净值、交易、成交和持仓等 CSV 文件，Excel 可直接打开。

## 自测题

先自己想一想，再点开答案核对。

**1. 想找出所有回测里夏普比率最高的一次，应该怎么做？**

> [!ANSWER]
> 在回测记录页点击「夏普」表头，按从高到低排序。顶部横幅也会直接显示最高夏普的那次回测。

**2. 想统计每笔交易的持仓天数分布，应该用导出包里的哪个文件？**

> [!ANSWER]
> 「交易记录.csv」，每一行是一笔完整交易，包含持仓天数。

**3. Excel 里 `=B3/B2-1` 算出的是什么？**

> [!ANSWER]
> 如果 B 列是净值，算出的是第 3 行这一天相对前一天的涨跌幅（日收益率）。
