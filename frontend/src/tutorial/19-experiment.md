# 用实验方法研究一个策略

前面学了很多工具，这一章把它们串起来：像做科学实验一样，完整地研究一个策略。

## 研究的五个步骤

| 步骤 | 要做的事 | 例子 |
|---|---|---|
| 1. 提出问题 | 你想知道什么？ | "均线周期越长，双均线策略的回撤越小吗？" |
| 2. 提出假设 | 你预期会看到什么？为什么？ | "越长越不容易被震荡打脸，所以回撤更小，但收益也可能更低" |
| 3. 设计实验 | 改什么、不改什么、怎么比较 | 只改长均线周期（20、30、60、120），其余全部默认 |
| 4. 运行与记录 | 跑回测，把结果填进表格 | 见下表 |
| 5. 分析结论 | 假设成立吗？为什么？有什么局限？ | 结合诊断分析写结论 |

## 控制变量

一次实验只改**一个**因素，其他条件必须完全相同：

| 必须保持不变 | 为什么 |
|---|---|
| 回测区间 | 不同区间的市场环境不同 |
| 标的 | 不同股票的特性不同 |
| 初始资金 | 资金量影响整手取整 |
| 交易成本 | 成本直接影响收益 |
| 其他参数 | 否则分不清是谁的影响 |

把每次回测的结果记下来，是研究最重要的习惯。建议的记录表：

| 编号 | 改动 | 年化收益 | 最大回撤 | 夏普 | 胜率 | 盈亏比 | 交易次数 | 成本占比 | 备注 |
|---|---|---:|---:|---:|---:|---:|---:|---:|---|
| 1 | 长均线 20 | | | | | | | | |
| 2 | 长均线 30（默认） | | | | | | | | 基准组 |
| 3 | 长均线 60 | | | | | | | | |

> [!TIP] 一定要有"基准组"
> 默认参数的结果是对照的基准，所有变化都要和它比。

## 一个完整的研究示例

**问题**：动量选股的"绝对动量过滤"能不能降低熊市回撤？

**假设**：开启过滤后，当股票池里大部分股票动量为负时会减仓甚至空仓，所以 2022 年这样的下跌年份回撤应该更小；代价是反弹初期可能踏空。

**实验设计**：

- 策略：动量选股，其他参数默认；
- 区间：2022-01-01 至 2025-12-31；
- 对照：关闭过滤（默认）vs 开启过滤。

**操作**：对助手说

```
动量选股回测 2022-01-01 到 2025-12-31，分别在关闭和开启绝对动量过滤两种情况下回测，对比最大回撤、年化收益和 2022 年的年度收益
```

**分析时要回答的问题**：

1. 开启过滤后，最大回撤变小了吗？变小了多少？
2. 年化收益是变高还是变低？
3. 年度收益图里，哪一年差别最大？
4. 「持仓明细」里，开启过滤后有没有空仓或持股很少的时期？
5. 这个结论在其他区间（比如 2018~2021）也成立吗？

## 写结论的格式

一个好的结论包含四部分：

1. **结果**：数据说明了什么（引用具体数字）；
2. **解释**：为什么会这样（结合策略原理）；
3. **局限**：这个结论在什么条件下可能不成立（区间、标的、幸存者偏差……）；
4. **下一步**：还想继续验证什么。

> [!KEY] 好结论的样子
> "在 2022~2025 年，开启绝对动量过滤后最大回撤从 −X% 降至 −Y%，但年化收益下降了 Z 个百分点。原因是 2022 年多数股票动量为负，策略大部分时间持股较少。该结论仅基于 55 只当前龙头股，存在幸存者偏差；下一步打算在 2018~2021 年重复实验。"
