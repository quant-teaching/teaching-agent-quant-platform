# 第一次对话：让智能助手帮你回测

智能助手是这个平台的核心。你不需要会编程，像跟老师说话一样提要求就行。

## 第一步：打开智能助手

点侧边栏最上面的 **「智能助手」**。首页有 6 张示例卡片，点任何一张都会直接发送那句话，最适合第一次体验。

## 第二步：说出你的需求

试着照抄下面这句话发送：

```
使用双均线策略，对沪深 A 股回测 2022-01-01 至 2025-12-31，并分析它在震荡市的表现
```

助手会一步一步地工作，每一步都显示成一个小标签：

1. **调取策略**：从算法库找到双均线策略；
2. **执行回测**：用你给的区间跑回测，大约一两秒；
3. **展示结果**：对话里出现回测卡片，右侧自动展开完整报告；
4. **解读分析**：结合指标、行情分段和诊断数据讲解策略表现，最后附上免责声明。

> [!TIP] 点开小标签看细节
> 每个步骤标签都可以点开，看到参数修改前后的对比、回测的关键数字等。

## 第三步：继续追问

对话是连续的，助手记得上下文，你可以接着说：

- "把短均线改成 5、长均线改成 20，再跑一次" → 修改参数并回测；
- "胜率为什么这么低？给我一个具体的参数优化建议，并实际验证一下效果" → 它会提出建议并真的跑回测对比；
- "短均线周期取 5、10、20 分别是什么效果" → 参数敏感性对比；
- "把这个参数组合保存成衍生策略" → 以后在算法库里也能调出来。

## 说话的小技巧

| 想要的效果 | 推荐说法 |
|---|---|
| 指定策略 | 说名字或别名："海龟策略""布林带""动量选股" |
| 指定时间 | 写清起止日期："2021-01-01 到 2024-12-31" |
| 指定标的 | "沪深 A 股""商品期货""申万行业"，或具体代码 "600519" |
| 改参数 | "ATR 周期改为 22，单笔仓位上限 0.15" |
| 只想学原理 | "给我讲下布林带策略的原理，它有哪些参数" |

> [!WARNING] 助手不会做的事
> 问"现在该买哪只股票""明天会涨吗"，助手会礼貌拒绝。这是教学平台，只讲算法原理和历史回测，不提供实盘投资建议。

> [!NOTE] 数字可信吗
> 回复里的指标数字都来自回测引擎，回复末尾会显示「数据核验」结果，告诉你有多少个数字核对过。
