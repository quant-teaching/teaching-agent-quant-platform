# 组合实验室：把策略组合起来

## 为什么要组合

俗话说"不要把鸡蛋放在一个篮子里"。不同策略在不同行情下各有输赢：

| 行情 | 趋势策略 | 均值回归策略 |
|---|---|---|
| 单边上涨 | 赚 | 可能亏（过早卖出或逆势） |
| 区间震荡 | 亏（频繁止损） | 赚 |
| 单边下跌 | 空仓或做空 | 可能亏（抄底被套） |

把两者组合在一起，一个亏的时候另一个可能在赚，**整体的回撤就会变小**。

> [!KEY] 组合的关键是"不同步"
> 两个策略收益的**相关系数**越低，组合起来分散风险的效果越好。相关系数接近 1 的两个策略几乎同涨同跌，组合了也没什么用；接近 0 甚至为负，效果最好。

## 一个简单的计算

两个策略各占 50%：

| | 策略 A | 策略 B | 组合 |
|---|---:|---:|---:|
| 第 1 年 | +20% | −5% | +7.5% |
| 第 2 年 | −10% | +15% | +2.5% |
| 第 3 年 | +15% | +5% | +10% |

单看 A 或 B，都有亏损年份；组合之后三年都是正的。这就是分散化。

## 操作步骤

![组合实验室：快速组合、子策略列表与权重](/tutorial/portfolio.jpg)

1. 打开 **「组合实验室」**；
2. 在 **「快速组合」** 里点一个预设：
   - 趋势 + 动量（股票）
   - 趋势 + 均值回归（期货）
   - 股票 + 期货 CTA
   - 红利 + 行业轮动 + 风险平价
3. 或者点 **「添加子策略」** 自己挑选。子策略使用各自的默认参数；想用自己调好的参数，可以先在算法库里「另存为衍生策略」，再把衍生策略加入组合；
4. **「等权」** 开关打开时平均分配资金；关闭后可以给每个子策略填写权重；
5. 选择 **组合再平衡**：
   - 不调仓：各部分资金自由涨跌，比例会逐渐偏离；
   - 每月 / 每季度：定期把各部分资金拉回目标比例；
6. 设置回测区间和初始资金，点 **「开始组合回测」**。

## 怎么看组合报告

组合报告比单策略多一个 **「组合分析」** 标签：

| 内容 | 看什么 |
|---|---|
| 子策略表现 | 每个子策略单独的收益、回撤、夏普；净值曲线上也会叠加各子策略 |
| 收益相关系数 | 子策略两两之间的相关系数矩阵，越接近 0 越好 |
| 分散化效果 | 组合波动率 vs 子策略加权平均波动率、分散化比率、平均相关系数、组合最大回撤 |

**分散化比率** = 子策略加权平均波动率 ÷ 组合波动率。大于 1 说明组合确实降低了波动，越大效果越好。

> [!TIP] 一个经典对比实验
> 分别回测"海龟交易法则"和"均值回归"两个期货策略，再用预设「趋势 + 均值回归（期货）」组合回测。比较三者的最大回撤和夏普比率，你会直观地看到分散化的作用。

## 在对话里做组合

也可以直接对助手说：

```
把海龟交易法则和均值回归做等权组合回测 2021-01-01 到 2025-12-31，分析两者是否互补
```

助手会执行组合回测，并重点分析相关系数和分散化效果。
